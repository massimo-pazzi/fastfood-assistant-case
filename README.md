# Как спроектировать ИИ-ассистента для приложения, не имея данных заказчика

Портфолио-кейс менеджера продукта с ИИ: видение ИИ-ассистента в мобильном
приложении федеральной сети быстрого питания для тендера, сентябрь 2025 года.
Заказчик не дал ни сценариев, ни статистики обращений — продукт собран из
открытых источников: темы обращений, границы продукта, мультиязычность,
дерево сценариев, нагрузка, метрики успеха.

**Страница кейса:** [massimo-pazzi.github.io/fastfood-assistant-case](https://massimo-pazzi.github.io/fastfood-assistant-case/)

Заказчик и подрядчик не называются; итог тендера не раскрывается.

## Структура

```
index.html              страница кейса (собирается скриптом)
report/case.md          текст кейса
scripts/model.py        темы обращений, дерево сценариев, расчёт нагрузки
scripts/build_page.py   сборка страницы из текста и модели
data/                   результаты расчётов в CSV
```

## Как пересобрать

```bash
python3 scripts/model.py
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_page.py
```
